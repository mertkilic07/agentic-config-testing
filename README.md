## Overview

Configurable software can be built and run in thousands of ways, and some bugs appear only when
certain options are combined. This project studies whether an **agentic AI** can identify such
option interactions that existing tests leave untested, and generate tests for them.

We use **SQLite** as the system under study. Before building the agent, we set up an experiment
that, for any configuration, builds SQLite, runs **SQLite's own test suite**, and measures code
coverage. Configurations are chosen with **2-way covering arrays** generated by NIST ACTS.

## Highlights so far

- ⚙️ **Automated pipeline:** ACTS covering array → build → option check → SQLite's Tcl tests → coverage, one command per configuration.
- 🔍 **Two silent constraints found** while screening 16 compile-time options:
  - `ENABLE_GEOPOLY` without `ENABLE_RTREE` builds and is reported as enabled, but geopoly functions do not exist.
  - On an `OMIT_WAL` build, `PRAGMA journal_mode=WAL` gives no error and silently keeps the old journal mode.
- 📉 **Covering array:** 6 configurations cover every pair of values of the pilot model (16 exhaustive).

## Quick start

Requirements: [Docker Desktop](https://www.docker.com/products/docker-desktop/) and git. Everything else is inside the image.

```sh
git clone https://github.com/mertkilic07/agentic-config-testing.git
cd agentic-config-testing
docker build -t ens491-sqlite .
docker run --rm -it -v "$PWD:/work" ens491-sqlite      # Windows PowerShell: -v "${PWD}:/work"
```

Inside the container:

```sh
python3 scripts/run_config.py --row 1 --scope main     # smoke test, about 1 minute
```

## Usage

| Goal | Command |
|---|---|
| Generate the covering array | `bash scripts/generate_acts.sh` |
| Run one configuration | `python3 scripts/run_config.py --row 3 --scope quick` |
| Run all configurations | `python3 scripts/run_config.py --all --scope quick` |
| Build the results table | `python3 scripts/make_table.py --scope quick > results/coverage_table.md` |
| Screen new candidate options | `python3 scripts/screen_options.py` |

`--scope` selects SQLite's test script: `main` (95 tests, seconds) or `quick` (about 590,000 test cases, 30–60 minutes).
How each step works: [docs/method.md](docs/method.md).
